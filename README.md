# Root2Hokkaido 2026 | 出発

北海道 8天7夜親子自駕行程網站（單一 HTML，無外部函式庫）。

## 部署到 GitHub Pages
1. 建立新的 repository（建議 Private 無法免費用 Pages，Public 請確認內容無個人資料）
2. 上傳 `index.html`、`.nojekyll`、`README.md`
3. Settings → Pages → Branch 選 `main`、資料夾 `/ (root)` → Save
4. 約 1 分鐘後網址：`https://<帳號>.github.io/<repo名稱>/`

## 注意
- 記帳與 Check list 儲存在各自瀏覽器（localStorage），不同裝置不會同步。
- 需雙人共用同步，請使用 Claude 上的版本。
